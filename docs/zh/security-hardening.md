# 安全加固（中文摘要）

> 完整清单见 [英文安全加固文档](../security-hardening.md)。

## 密钥与配置

- [ ] `STRATA_JWT_SECRET` 随机 ≥32 字符，每环境独立，存于密钥管理；轮换保留旧密钥过渡窗口。
- [ ] `STRATA_ADMIN_PASSWORD` ≥16 字符、非占位，首次登录后修改。
- [ ] 数据库/Redis 口令不落仓库；字段加密（AES 插件）按合规要求开启，密钥外部管理。
- [ ] 保持启动守卫开启：占位密钥与通配 CORS 必须让进程启动失败。

## 网络与传输

- [ ] TLS 在代理/Ingress 终结；应用端口只监听本地/内网。
- [ ] 管理端口 8081 不对外暴露。
- [ ] CORS 精确源；登录/昂贵接口配置限流；集群部署登录锁定使用 Redis。
- [ ] 安全响应头（CSP、HSTS、X-Content-Type-Options）在代理侧就绪；Cookie 使用 `__Host-`/Secure/SameSite。

## 认证授权

- [ ] RBAC 最小权限，不使用种子 admin 日常操作。
- [ ] MFA：已内置按用户 TOTP（按用户可选开启）；为特权管理员开启，设置 `STRATA_ENCRYPTION_KEY` 以便重启后仍可解密，并保留管理员重置通道（见 [MFA 指南](./mfa.md)）。
- [ ] OIDC/SAML：PKCE、精确回调、组→角色映射验证；SCIM token 独立管理。
- [ ] 玩家端接口（私有产品）与员工端接口分离。

## 数据与审计

- [ ] 审计保留与导出符合策略；日志不含凭据/完整实体。
- [ ] 备份加密、异地、定期恢复演练。
- [ ] 资金/状态变更客户端重试使用幂等键。
- [ ] 多租户：社区版为目录级租户；行级隔离为私有/Pro 扩展点。

## 供应链

- [ ] 归档每次发布的 SBOM（`bom.json`），关注 Dependabot 与安全公告。
- [ ] 公开 CI 的 Trivy 锁文件扫描与 PR 依赖审查保持开启。
- [ ] 校验 Maven Central 构件签名/校验和。
