# Configuration reference

> Generated by `scripts/generate-config-reference.mjs` from the per-module
> `META-INF/spring-configuration-metadata.json` files that the build produces; **do not edit this page by hand**.
> To change a property, edit the corresponding `@ConfigurationProperties` class and regenerate; CI verifies that this
> page matches the code.
>
> Prerequisite: `cd strata && mvn -DskipTests compile` (add `-o` for an offline build).
>
> Environment variable override: Spring Boot relaxed binding, e.g. `strata.security.jwt.secret` →
> `STRATA_SECURITY_JWT_SECRET`. In production prefer environment variables over editing yml.
