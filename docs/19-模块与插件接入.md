# 模块与插件接入

> 面向使用开源框架的团队：如何新增一个业务模块、如何实现插件 SPI、以及扩展点如何替换默认实现。

## 1. 新增业务模块（api / biz / web 分层）

以 `examples/strata-module-example` 为模板复制即可：

```
strata-module-example/
  pom.xml                       # parent: strata-<domain>，复用根依赖管理
  src/main/java/dev/strata/example/
    api/  entity/ request/ dto/  # 跨模块可见的对象与实体
    biz/  repository/ service/   # 业务实现（事务边界在这里）
    web/  XxxController.java     # 只做参数校验 + 调 service
  src/main/resources/
    META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports
```

约定：

| 规则 | 说明 |
| :--- | :--- |
| 依赖方向 | web → biz → api；biz 不反向依赖 web，跨模块只依赖对方的 api 模块 |
| 实体与仓库 | 放在 api / biz 模块，由 `@EntityScan` / `@EnableJpaRepositories` 扫描 |
| 事务 | 在 service 方法上 `@Transactional`，controller 不写事务 |
| 测试 | 每个模块至少一个 slice 测试；需要数据库时用与 `strata-minimal-app` 相同的动态属性写法 |

模块若需要被 starter 自动装配，提供自己的 `@AutoConfiguration` 并写入 `AutoConfiguration.imports`（参考
`examples/strata-module-example/src/main/java/dev/strata/example/ExampleAutoConfiguration.java`）。

## 2. 插件 SPI（可选能力）

插件放在 `strata-plugin`，依赖 `strata-plugin-api` + `strata-common-core`，实现 SPI 接口后自带
`AutoConfiguration`：

| 插件 | SPI | 说明 |
| :--- | :--- | :--- |
| `strata-plugin-llm-openai` | `LlmGateway` | OpenAI 兼容网关，AI 模块必需之一 |
| `strata-plugin-storage-local` | `StorageProvider` | 本地/对象存储 |
| `strata-plugin-stripe` | `PaymentGateway` | Stripe 支付 |
| `strata-plugin-excel` | Excel 导入导出 | 通用工具 |
| `strata-plugin-encrypt-aes` | `FieldEncryptor` | 字段级加密 |
| `strata-plugin-workflow-flowable` | 工作流引擎 | Flowable 集成 |

插件是否生效由 `@ConditionalOnProperty` 控制（如 `strata.plugin.llm.openai-compatible.enabled`），
消费者添加依赖即可，无需扫描配置。

## 3. 扩展点（SPI 默认实现可被替换）

框架提供三个"宿主实现"接口，默认实现只记录日志、不做真实副作用；声明同名 bean 即覆盖：

| 扩展点 | 默认行为 | 典型实现 |
| :--- | :--- | :--- |
| `VerificationSender` | 记录"验证码已请求" | SMTP 邮件 / 短信网关 / 消息中心 |
| `BackupExecutor` | 记录备份意图，不执行 | pg_dump + 对象存储 |
| `AuditChangeApplier` | 拒绝回放（返回 false） | 按审计记录恢复实体 / 走审批流 |

示例：

```java
@Configuration
class MailConfig {
    @Bean
    VerificationSender verificationSender(MailClient mail) {
        return new VerificationSender() {
            public void sendEmailVerificationCode(String email, String code) { mail.send(email, code); }
            public void sendSmsVerificationCode(String phone, String code) { /* 短信网关 */ }
        };
    }
}
```

默认实现由 `strata-system-rbac-biz` / `strata-system-ops-biz` 的 `@Configuration` 注册，
自带 `@ConditionalOnMissingBean`，因此覆盖不会造成重复 bean。
