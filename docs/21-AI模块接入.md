# AI 模块接入

> AI 是可选能力：核心 starter 不依赖 AI 模块，添加依赖即自动装配。

## 1. 最小接入

```xml
<dependency>
  <groupId>io.github.simplezac1995</groupId>
  <artifactId>strata-ai-biz</artifactId>
</dependency>
<dependency>
  <groupId>io.github.simplezac1995</groupId>
  <artifactId>strata-plugin-llm-openai</artifactId>
</dependency>
```

`strata-ai-biz` 会传递 chat / knowledge / config 等子模块；`AiAutoConfiguration` 扫描 `dev.strata.ai`
的组件、实体与仓库，不需要消费者写 scanBasePackages。LLM 插件提供 `LlmGateway` 实现，否则 AI 模块启动时
会因缺少网关失败（这是有意的显式依赖）。

## 2. 关键配置

```yaml
strata:
  ai:
    enabled: true
    # 模型/供应商配置存于 sys_ai_provider / sys_ai_model 表，可在管理端维护
  plugin:
    llm:
      openai-compatible:
        enabled: true
        base-url: https://api.openai.com/v1
        api-key: ${OPENAI_API_KEY}
```

敏感配置不要写入 yml 提交到仓库：用环境变量或 AES 加密插件（`strata-plugin-encrypt-aes`）。

## 3. 权限与菜单

AI 页面使用 `ai:*` 权限（`ai:chat:list`、`ai:knowledge:list`、`ai:model:list` 等），
由 `AiOpsMenuSeedContributor` 在种子数据中注册；管理端菜单随 RBAC 权限显示。

## 4. 扩展点

| 场景 | 方式 |
| :--- | :--- |
| 换 LLM 供应商 | 实现 `LlmGateway` 并声明 bean，覆盖默认 OpenAI 兼容网关 |
| 向量库 | `AiVectorStore` 相关服务可替换为自己的实现（默认 pgvector/表存储） |
| 用量计费 | `AiUsageRecorder` 提供每模型 token 用量；计费价格表属于业务侧扩展 |
| 自定义工具 | 管理端「AI Skills / 工具」页面注册，或实现 `AiToolHandler` 扩展（见 ai-biz） |

## 5. 测试

`examples/strata-minimal-app` 已包含完整链路测试（Flyway 建表 → Hibernate validate → AI 自动装配 →
Swagger 分组），修改 AI 模块后可先跑：

```bash
mvn -B -pl examples/strata-minimal-app -am -Dtest=MinimalApplicationSmokeTest test
```
