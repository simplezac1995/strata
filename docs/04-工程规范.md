# 04 · 工程规范（后端 + 前端）

> 本文是命名、分层、API、ORM、日志、配置、格式化与前端组织的权威规范，已对照仓库实际代码核实。
> 与 `.cursor/rules/strata-conventions.mdc`、`strata-backend.mdc`、`strata-frontend.mdc` 冲突时，以硬锁文件为准。

---

## 第一部分 · 后端

### 1. 包结构

- 根包 `dev.strata`，主类 `dev.strata.app.StrataApplication`。
- 领域按 Maven 模块划分，每域再拆 `-api`（契约）与 `-biz`（实现）：

```
dev.strata.common.{core,security,data,oss,excel,lock,sse,sensitive,datasource,redisson,websocket,tracing,xss,logging}
dev.strata.system.{rbac,ops,config,communication}.{api,biz}
dev.strata.ai.{chat,knowledge,config}.{api,biz}
dev.strata.pro.*
dev.strata.enterprise.*
dev.strata.casino.{wallet,player,game}.{api,biz}
dev.strata.plugin.*
dev.strata.app                 # 装配层（config / 启动守卫 / 集成测试）
```

- 同一类型只允许一处定义（`Ai*` 只在 `strata-ai-api`）；目录名与包名必须一一对应。

### 2. 分层

| 层 | 包 | 职责 |
| :--- | :--- | :--- |
| Controller | `...biz.web` | 参数绑定、鉴权注解、调 AppService、返回 `Result` |
| AppService | `...biz.appservice` / `...biz.service` | 用例编排、事务边界；横切 `*Service` 走 `service.support` 白名单 |
| Repository | `...biz.repository` | Spring Data JPA 接口，仅数据访问 |
| Domain / DTO | `...api.entity`、`...api.dto` | 实体与出入参，只有 `*-api` 可被跨域依赖 |

- Controller 不直接注入 Repository；跨域调用走对方 `*-api` 暴露的端口接口，不直接读对方表。
- HTTP 入口一律放在 `...biz.web`（ArchUnit `controllersLiveInWebPackages` 锁定；`docs/17` 为结构约定权威）。
- 权限注解一律引用 dev.strata.common.security.auth.Permissions 常量，禁止内联 hasAuthority('...') 字面量（2026-11 已全量替换 472 处；新增权限时先加常量、再在 RBAC seed 里授予同名权限）。
- DTO ↔ 实体一律 **MapStruct**（1.6.x），禁止手写大面积 getter/setter 拷贝。
- Mapper 统一在 `...biz.mapper` 包；唯一例外是 system-biz 的 `demo` 教学包（刻意就近，不得扩散）。
  不要采用生成器历史模板里的 `biz/service/mapper` 扁平路径。

### 3. REST API

**两套边界**：staff `/api/v1/<域>/...`；player `/v1/...`（见 03-架构设计）。

- 成功：返回 `Result<T>`（`dev.strata.common.core.web.Result`）；`ResultTraceAdvice` 自动从 MDC 回填 `traceId`。
- 错误：RFC 7807 Problem Details（`application/problem+json`），由 `ProblemDetails` 工厂统一生成，
  字段固定 `type/title/status/detail/code/timestamp/traceId`。
- 全局处理：`GlobalExceptionHandler`；安全链侧 `SecurityExceptionHandler`；玩家侧 `PlayerApiExceptionHandler`；
  限流 / 幂等等横切件用各自 `ProblemDetail*Writer` 输出同形错误体。
- 方法语义：`GET` 查询、`POST` 创建/动作、`PUT` 全量更新、`DELETE` 删除；**禁止 `PATCH`**。
- 分页走服务端分页；列表 `limit` 服务端钳制上限；慢查询阈值 1000ms。
- 鉴权：方法级 `@PreAuthorize` + 权限串 `module:entity:action`（如 `system:user:list`），
  动作只用 `create|update|delete|list`；权限串与 kebab-case URL 的映射见 ADR-0014。
- API 版本：URI 前缀 `/api/vN/...` + 可选 `X-API-Version` 请求头，由
  `dev.strata.common.core.apiversion.ApiVersionInterceptor` 解析并写入 `ApiVersionContext`。
  弃用治理：在 `strata.api.version.deprecated-versions` / `deprecated-paths` 列出弃用版本或端点，
  拦截器会统一回写 `Deprecation: true`、`Sunset: <RFC-1123>` 与可选 `Link: <doc>; rel="deprecation"`
  响应头，**不需要改 controller**；`sunset` / `deprecation-link` 为空时对应头省略。

### 4. JPA 与数据

- `@Entity` + `@Table(name = "sys_xxx")`，表名 / 列名小写下划线（`created_at`、`created_by`）。
- **ID 统一雪花算法** `dev.strata.common.core.util.IdGenerator`（64bit，纪元 2024-01-01 UTC，
  worker 取 `STRATA_WORKER_ID` 默认 1，含时钟回拨保护）；**禁止** `IDENTITY`/`AUTO` 与自增列混用。
- 审计四列 `createdAt/createdBy/updatedAt/updatedBy`（`@EnableJpaAuditing`）。
- 所有 profile `ddl-auto=validate`：结构以 Flyway 为准，实体只校验、不建表。
- 批量：Hibernate `batch_size=50`、`order_inserts/order_updates=true`；PostgreSQL JDBC
  `reWriteBatchedInserts=true`。
- 数据访问只走 Spring Data JPA / 参数化查询；**核心禁止 MyBatis-Plus 与第二套 ORM**。
- PostgreSQL-only 迁移纪律见 06-数据与持久化。

### 5. 异常与业务错误

- 业务错误码统一登记在 `ErrorCode` 枚举（`status()` + `code()`），抛业务异常由处理器翻译成 ProblemDetails。
- 新增错误：先加枚举值再抛；不要在 Controller 手搓 JSON。

### 6. 日志

- 门面 **SLF4J**，禁止 `System.out` 与裸 `java.util.logging`。
- 每行可关联 traceId：`TraceIdFilter` 写 MDC 并回传 `X-Trace-Id`；console pattern 含 `%X{traceId:-}`。
- prod 用 `logstash-logback-encoder` 输出 JSON（面向 Loki/ELK）；慢 SQL >1000ms 自动记录；
  Hikari 连接持有超阈值记录泄漏栈。
- 敏感字段不得入日志：实体避免全字段 `toString()` 泄露凭据，必要时用 `@ToString.Exclude`。

### 7. 配置

- `strata-app/src/main/resources/application.yml` 为基线，叠加 `application-<profile>.yml`。
- profile：默认=PostgreSQL + Redis；`prod`=PostgreSQL 严格超集（profile group）；
  `perf`=压测专用（豁免启动守卫与限流，禁真实流量）；`demo`=演示开关。
- 敏感配置走环境变量或 Jasypt `ENC(...)`（`PBEWITHHMACSHA512ANDAES_256`，口令来自
  `JASYPT_ENCRYPTOR_PASSWORD`），禁止硬编码。
- 新配置键统一挂 `strata.*` 命名空间，在 `application.yml` 给默认值与注释；新增必填项同步更新
  `deploy/.env.example` 与 `SecurityRuntimeGuard` 规则。

### 8. 构建期硬门禁

| 插件 | 作用 |
| :--- | :--- |
| spotless 2.44.x | Palantir Java Format；SPDX 头 `// SPDX-License-Identifier: Apache-2.0`；去未用 import / 尾空白；`verify` 强制 `spotless:check` |
| maven-compiler | release=21、`parameters=true`，注解处理 = Lombok + MapStruct |
| maven-surefire | 挂 JaCoCo + Mockito agent；测试 JVM 注入 `STRATA_ADMIN_PASSWORD` 以满足启动守卫 |
| jacoco | prepare-agent + report；模块级 `check` 锁 INSTRUCTION + BRANCH 双轨防回退地板（见 07-测试策略） |
| spring-modulith / archunit | 仅 test 期模块与分层边界校验 |

提交前最少：`cd strata && mvn spotless:apply && mvn verify`。

## 第二部分 · 前端（`strata-ui/`）

栈：React 19 + TypeScript 6 + **MUI 9** + Vite 8 + TanStack Query 5 + Zustand 5。无 Tailwind / lucide（ADR-0013）。

### 9. 目录结构

```
strata-ui/src/
├── main.tsx / App.tsx          # 入口与根组件
├── index.css                   # 仅 baseline，不写业务样式
├── pages/                      # 页面：system/ ai/ pro/ plugins/ tools/ settings/ demo/ auth/
├── components/
│   ├── ui/                     # 基础件统一封装层（唯一允许直接拼业务的入口）
│   ├── shell/                  # 布局壳（侧栏/顶栏）
│   ├── NotificationCenter/     # WebSocket 通知
│   └── ai/
├── shared/
│   ├── api/                    # axios client + 按域分文件（auth/system/ai/pro/generator/demo…）
│   ├── query/                  # TanStack Query 客户端与 hooks
│   ├── auth/ hooks/ websocket/ i18n/ pwa/ monitoring/ performance/ pageKit/
├── routes/                     # appRoutes.tsx / lazyPages.ts / routeTable.tsx / guards.tsx
├── theme/                      # MUI theme
└── context/
```

路径别名 `@` → `./src`，跨层引用统一 `@/…`。

### 10. 组件与样式

- 函数组件 + TypeScript，禁 class 组件；页面文件 **PascalCase**，路由路径 **kebab-case**。
- 业务页只用 `components/ui` 二次封装的基础件（`Button/Dialog/DataTable/QueryForm/Pagination/Fields/Alert/
  Badge/Chips/Layout/VirtualList/ErrorBoundary` + `chart/`），不直接散落原生 MUI 拼业务；新增通用件先入
  `components/ui` 并配 `*.test.tsx`。
- 样式优先 `sx` 与 `theme`，禁止新增全局业务 CSS。
- 可访问性：可点控件带 accessible name，`ErrorBoundary` 兜底，语义化 HTML。

### 11. 状态与数据

- **服务端状态 → TanStack Query**（`shared/query`）：GET 用 query，写操作用 mutation + 失效；
  不用 Zustand 缓存服务器数据（ADR-0030）。
- **本地 / UI 状态 → Zustand**（主题、抽屉、弹窗）；组件短期状态用 `useState`。
- API 统一走 `shared/api/client.ts`（axios 实例，错误处理 + 令牌注入），按域分文件；
  类型由 OpenAPI 生成（`pnpm generate:api-types`），手写 DTO 不得与生成类型漂移。
- 路径与后端边界一致：staff `/api/v1/...`、player `/v1/...`；Vite dev 代理 `/api`、`/actuator` 到 8080。

### 12. 路由与性能

- 路由表集中 `routes/appRoutes.tsx`，懒加载清单 `lazyPages.ts`，守卫 `guards.tsx`；除首屏外页面一律 `lazy()`。
- 菜单 / 按钮权限码与后端 `@PreAuthorize` 串一致。
- 分包在 `vite.config.ts` `manualChunks` 固化（mui/axios/emotion/react-vendor/react-query/bpmn-js/i18n）；
  bpmn-js 独立大 chunk 属预期；门禁锁单 chunk ≤ 600 kB。
- 大列表用 `VirtualList`，查询表单用 `QueryForm`，图表走 `components/ui/chart`；
  `memo/useMemo/useCallback` 只在实测昂贵时使用。体积分析 `ANALYZE=true pnpm build`。

### 13. i18n

- 所有可见文案走 `t()` 语义键（`domain.key`，禁 `text.*` 裸串与 `keyMap` 残留），字典在 `shared/i18n`（zh/en）。
- 门禁：`pnpm i18n:verify`（引用↔字典对齐）、`pnpm i18n:scan`（扫硬编码）、`pnpm i18n:patch`（补中文）。

### 14. 命名速查

| 对象 | 规则 |
| :--- | :--- |
| 页面 / 组件文件 | PascalCase（`DataTable.tsx`） |
| 路由路径 | kebab-case |
| hooks | `useXxx` |
| API 函数 | 动词开头对齐 HTTP 语义：`listUsers/createUser/updateUser/deleteUser` |
| 常量 | UPPER_SNAKE_CASE；布尔 `isXxx/hasXxx/canXxx` |
| 后端表 / 列 | `sys_xxx` / 小写下划线 |
| 后端权限串 | `module:entity:action`，动作仅 `create/update/delete/list` |
| 样式 | 不写全局类名，走 theme/sx |

### 15. 前端门禁

| 命令 | 作用 |
| :--- | :--- |
| `pnpm check` | 综合门禁（CI frontend job 执行）：typecheck + oxlint + knip + vitest + i18n×2 + prettier + build + 体积 |
| `pnpm typecheck` / `pnpm lint` / `pnpm test` / `pnpm format:check` | 单项 |
| `pnpm e2e` | Playwright（首次先 `pnpm e2e:install`） |

### 16. 浏览器兼容

- **支持矩阵**：Chrome/Edge ≥ 90、Firefox ≥ 90、Safari ≥ 14（对应 `package.json` 的
  `browserslist` 字段）。不再正式支持 IE 与上述版本以下的旧浏览器。
- **viewport**：`index.html` 已声明 `<meta name="viewport" content="width=device-width, initial-scale=1.0">`，
  所有响应式布局以该宽度为基准，禁止再写死桌面像素宽度。
- **构建目标**：`vite.config.ts` `build.target = "es2022"`（原生 ESM / 动态 import / `import.meta`）。
  该值与 `browserslist` 共同约束 esbuild 转译目标；新增用到的新语法需先确认在支持矩阵内可用，
  必要时在 `browserslist` 收紧或加 polyfill，不要只靠运行时报错兜底。
- **公开法律页**：`/legal/terms`、`/legal/privacy`、`/legal/cookie` 为公开路由（在 `routeTable.tsx`
  顶层声明，不走 AppShell / RequireAuth），结构与上述响应式约束一致；正文当前为占位文本，
  GA 前由法务提供正式版本并迁入 `shared/i18n` 字典。
