# Support

## Where to ask

- **Bug reports / feature requests**: open an [issue](https://github.com/simplezac1995/strata/issues) with the bug or
  feature template.
- **Documentation questions**: start with the [documentation site](https://docs.simplecharlie.dev) and the
  [FAQ](docs/faq.md); if the answer is missing, open an issue labelled `documentation`.
- **Security vulnerabilities**: never open a public issue — follow [SECURITY.md](SECURITY.md) (private reporting).
- **Commercial / enterprise questions**: contact the maintainer listed in [MAINTAINERS.md](MAINTAINERS.md).

## What to expect

Strata is 0.x and maintained by a single maintainer: responses are best-effort, usually within a few business days.
There is no SLA. Reproducible bug reports with a minimal example get priority; questions that could become
documentation improvements are welcome as issues.

## Before opening an issue

1. Check the [FAQ](docs/faq.md), [Getting started](docs/tutorials/getting-started.md) and
   [Decisions](docs/decisions.md) for known trade-offs.
2. Reproduce on the latest release and include the version from `GET /v3/api-docs` (or the GitHub release tag).
3. Include the JDK version (build/run), database version, the exact command and the relevant log lines with secrets
   redacted.
